# YOLO 学习项目

本仓库记录 YOLO 目标检测方向的学习与实践。每个子目录是一个独立、可运行的项目。

## 项目列表

| 项目 | 内容 | 状态 |
| --- | --- | --- |
| [project-01-image-video-detection](project-01-image-video-detection/) | 基于 YOLOv8 和 OpenCV 的图片、视频目标检测 | 已完成 |
| [project-02-traffic-perception-analysis](project-02-traffic-perception-analysis/) | CPU 下的目标跟踪、越线计数与置信度统计 | 进行中 |

## 开发环境

- Python 3.12
- Ultralytics 8.4.137
- OpenCV 5.0.0

## 后续计划

1. 完成交通场景的跟踪、计数与置信度分析。
2. 使用自定义数据集训练 YOLO 模型。
3. 将检测结果接入机器人感知任务。
